About the Website

ShopeEasy is a frontend online shopping website designed to provide a simple and convenient shopping experience.

Users can browse products, search for products, add products to their wishlist and shopping cart, set a personal shopping budget, compare sample prices and place orders.

The website is developed using HTML, CSS and JavaScript.

  • Product Search
